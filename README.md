# Phishing Awareness Android

Applicazione Android sviluppata nell’ambito di una tesi di laurea per la generazione locale di esercizi di cybersecurity awareness basati su email di phishing simulate.

## Stato del progetto

Fase corrente: inizializzazione dell’app Android e implementazione del flusso grafico con dati simulati.

## Scenari attivi

- BANKING
- ACCOUNT_IT

## Architettura prevista

- Single Activity
- Fragment
- Navigation Component
- ViewModel
- LiveData
- RecyclerView
- Libreria JSON versionata
- Inferenza locale tramite llama.cpp

## Roadmap

1. Interfaccia Android simulata
2. Libreria JSON
3. Prompt builder
4. Parsing e validazione
5. Integrazione llama.cpp
6. Test su dispositivo
